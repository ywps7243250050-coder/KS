KostService website

CARA MENJALANKAN:
1. Ekstrak file ZIP.
2. Pastikan index.html dan beranda-kostservice.png berada dalam folder yang sama.
3. Klik dua kali index.html atau buka dengan browser.

TOMBOL YANG SUDAH AKTIF:
- Menu Beranda, Layanan, Harga, Tentang Kami, Testimoni, dan Kontak membuka panel informasi.
- Tombol pesan membuka formulir pemesanan.
- Setelah formulir diisi, pesanan disiapkan dan dibuka di WhatsApp nomor 0821-1493-3545.
- Tombol WhatsApp langsung membuka chat.
